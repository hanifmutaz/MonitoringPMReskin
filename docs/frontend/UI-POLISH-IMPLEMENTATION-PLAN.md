# UI Polish — Rencana Implementasi Sistematis

> **Turunan dari:** `UI-CONSISTENCY-AUDIT.md` (Fase 0).
> **Filosofi:** Design-system-first. Sentuh PRIMITIVE sekali → propagasi otomatis.
> **Prinsip lu (di-hormati):** scope disiplin, nol ubah logic/data, satu perubahan = satu keputusan sadar (didokumentasi), maintainable > pinter.
> **Aturan emas:** JANGAN rombak fondasi yang udah bagus (token, semantic color, component separation, audit trail). Cuma POLES.

---

## 0. Ringkasan strategi

**Kenapa urutan ini:** tiap fase berdiri di atas fase sebelumnya. Motion (F3) percuma kalau komponennya (F1) belum konsisten. Poles halaman (F2) percuma kalau primitive-nya (F1) belum final. **Aturan kerja tiap langkah:** 1. 1 PR / 1 batch = 1 concern (jangan campur "radius" + "motion" sekaligus). 2. Sebelum ubah primitive → grep pemakaiannya, catat berapa halaman kena. 3. Tiap keputusan visual → tulis komentar `// polish:` di kode + update audit. 4. Habis tiap fase → screenshot before/after (pakai dummy seed biar keliatan). --- ## FASE 1 — PRIMITIVE (fondasi) > Target: begitu ini beres, mayoritas halaman rapi TANPA disentuh langsung. ### 1.1 `utils/formatDate.js` ⏱️ paling instan (A1) - **Buat:** `formatDate(v)` → `04 Jul 2026`; `formatDateTime(v)` → `04 Jul 2026, 14:30`; `formatRelative(v)` → "3 hari lalu" (opsional). - **Pakai:** `dayjs` + `locale('id')` (udah keinstall). - **Ganti:** semua render tanggal mentah (History PM Part/Line, Audit Log, Inventory History, `last_tgl_ganti`). Cari: regex `toISOString|new Date\(|\.split\('T'`. - **Risiko:** nol (util murni). **Dampak:** langsung ilang kesan "murahan". - **Definition of done:** nol string ISO mentah di UI. Grep bersih. ### 1.2 `ui/card.jsx` — radius + elevation final (A2, A3) - **Keputusan (LOCK dulu):** radius standar = **rounded-xl** (D1). Elevation: panel pasif flat, surface hero (KPI) boleh shadow-sm + hover (D2). - **Ubah:** `card.jsx` naik ke `rounded-xl`. Samain `KpiCard`, `NeedsDataCard` udah `rounded-xl`. Pastiin nggak ada lagi `rounded-lg` liar di surface utama. - **Risiko:** MENENGAH — propagasi ke semua halaman yang pakai Card. Justru itu tujuannya, tapi WAJIB screenshot spot-check tiap grup halaman. - **DoD:** semua surface utama 1 radius. Konsisten lintas 14 halaman. ### 1.3 `ui/table` / `DataTable` — row & cell baku (A4) - **Standarisasi:** cell `px-2.5 py-2.5`, header `text-[11px] uppercase font-mono text-faint border-b`, row hover `bg-panel-2`, border-soft antar-row. - **Fix spesifik:** Monitoring Monthly/Weekly — ketepatan jadi **inline badge** (D4), bukan baris ke-2. Row balik 1 baris → padat. - **Risiko:** MENENGAH (semua tabel kena). **Dampak:** density naik drastis. - **DoD:** semua tabel 1 bahasa. Nggak ada row 2-baris kecuali disengaja. ### 1.4 `ui/empty-state` — audit pemakaian (A5) - **Cek:** semua kondisi kosong di 14 halaman pakai `<EmptyState>` (icon+title+desc). Ganti sisa teks polos ("Semua Line OK" dll). - **Risiko:** rendah. **DoD:** nol empty state teks-polos. ### 1.5 `KpiCard` — glow tuning (A6) - **Ubah:** shadow badge → `0_4px_12px_-5px`. Value tetap fokus utama. - **Risiko:** rendah (lokal). **DoD:** value > badge dalam hierarki visual. **Exit Fase 1:** screenshot semua halaman utama. Bandingin sama baseline. Harusnya ~60% udah "naik kelas" cuma dari langkah 1.1–1.3. --- ## FASE 2 — DOMAIN (poles per-grup) > Halaman mirip digarap bareng biar konsisten & hemat. ### 2.1 Grup Monitoring (Part / Line / Monthly / Weekly) - Terapin `DataTable` baru (dari 1.3). - Ketepatan inline badge. Progress ring per-part konsisten (siapin buat viz F3). - Layout header halaman seragam (judul, filter, action) — 1 pola. ### 2.2 Grup Master Data / Users / Inventory - Form field seragam (label, input, helper, error) — audit `ui/input`, `ui/select`, `ui/label`. - Tabel pakai DataTable. Action buttons (edit/hapus) 1 pola + posisi konsisten. ### 2.3 Grup History / Audit Log / Recycle Bin - Tabel + `formatDate` (dari 1.1). Kolom timestamp seragam. - Badge aksi (create/update/delete) pakai bahasa StatusBadge. **Exit Fase 2:** semua halaman pakai primitive yang sama. Nol komponen "one-off". --- ## FASE 3 — MOTION + DATA-VIZ (nyawa / "kesan mahal") 🔥 > Ini yang bikin MUI kerasa "hidup" & jadi biang rasa nggak puas lu. > Detail scale ada di `UI-CONSISTENCY-AUDIT.md` §6. ### 3.1 Motion tokens (A10) — pondasi - **Tambah di `tailwind.css`/config:** durasi (fast/base/slow/data), easing (standard/decelerate/accelerate) sebagai util class / CSS var. - **Wajib:** utility `@media (prefers-reduced-motion: reduce)` yang matiin animasi non-esensial. Ini nggak boleh skip. ### 3.2 Pola motion (urut dari dampak tertinggi) 1. **Hover lift** semua row/card interaktif (base). — murah, langsung kerasa. 2. **Fade-in-on-mount** panel + **stagger 40ms** grid KPI. — "mengalir". 3. **Skeleton → content crossfade** (jangan loncat). — udah 1/2 jalan. 4. **Number count-up** KPI (0→nilai, data durasi). — high-impact "premium". 5. **Tab indicator slide** (Monitoring tabs, dll). 6. **Modal/Drawer** enter/exit (slow/accelerate). 7. **Status flash** pas data berubah jadi DANGER (pulse 1×). - **Lib:** default pure CSS/Tailwind. `framer-motion` OPSIONAL cuma buat stagger/exit kompleks — timbang bundle dulu (lu sensitif soal ini, 129KB). ### 3.3 Data-viz konsisten (A11) - **Cek lib** yang udah keinstall (recharts? chart.js?). Kalau belum & simpel, SVG murni. - **Bahasa viz = token status** (ok/warn/danger). Sparkline mini di KPI (trend harian), progress ring per-part (udah ada di Monitoring — jadiin standar), trend bar Bekidoritsu (kalau relevan). - **Ini keunggulan vs MUI** — MUI nggak kasih ini gratis. Manfaatin. **Exit Fase 3:** buka app kerasa "hidup" — hover responsif, load mengalir, angka count-up, chart nyawa. Ini titik "anjir ini aplikasi beneran ya". --- ## FASE 4 — GLOBAL POLISH & QA - **Typography scale (A7):** kunci display/heading/body/label/caption di doc + terapin. Lompatan ukuran lebih tegas. - **Spacing rhythm (A8):** section 20 / panel pad 18 / grid gap 16 — konsisten. - **Icon pass (A9):** 1 set (Lucide), stroke-width seragam, buang icon berlebih (per permintaan lu "ikon seperlunya"). - **Dark theme final:** kontras, border-soft, elevation di dark mode. - **Accessibility QA:** focus ring, kontras WCAG, reduced-motion, keyboard nav, aria pada tabel (udah ada sebagian). - **Cross-check:** buka 14 halaman berurutan — harus kerasa "satu keluarga". --- ## Prioritas eksekusi (kalau mau mulai HARI INI) | Urutan | Item | Kenapa duluan | Risiko | |--------|------|---------------|--------| | 1 | `formatDate.js` (1.1) | instan, nol risiko, kesan naik | 🟢 | | 2 | `card.jsx` radius (1.2) | propagasi terluas | 🟡 | | 3 | Motion tokens + hover lift (3.1, 3.2#1) | "kesan mahal" paling cepet kerasa | 🟢 | | 4 | `DataTable` (1.3) | density Monitoring | 🟡 | | 5 | count-up + stagger (3.2#2,4) | wow-factor | 🟢 | > Catatan: gua sengaja naikin sebagian MOTION (F3) ke atas, karena itu jawaban langsung ke rasa nggak puas lu ("kalah elegan sama MUI").
