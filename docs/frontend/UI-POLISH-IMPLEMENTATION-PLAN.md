# UI Polish — Rencana Implementasi Sistematis

> **Turunan dari:** `UI-CONSISTENCY-AUDIT.md` (Fase 0).
> **Filosofi:** Design-system-first. Sentuh PRIMITIVE sekali → propagasi otomatis.
> **Prinsip lu (di-hormati):** scope disiplin, nol ubah logic/data, satu perubahan = satu keputusan sadar (didokumentasi), maintainable > pinter.
> **Aturan emas:** JANGAN rombak fondasi yang udah bagus (token, semantic color, component separation, audit trail). Cuma POLES.

---

## 0. Ringkasan strategi

**Kenapa urutan ini:** tiap fase berdiri di atas fase sebelumnya. Motion (F3) percuma kalau komponennya (F1) belum konsisten. Poles halaman (F2) percuma kalau primitive-nya (F1) belum final. **Aturan kerja tiap langkah:** 1. 1 PR / 1 batch = 1 concern (jangan campur "radius" + "motion" sekaligus). 2. Sebelum ubah primitive → grep pemakaiannya, catat berapa halaman kena. 3. Tiap keputusan visual → tulis komentar `// polish:` di kode + update audit. 4. Durasi TERNYATA nggak bisa lewat jalur sama — Tailwind v4 cuma dukung `--ease-*` sebagai custom theme namespace, `--duration-*` di-drop diam-diam. Fix: durasi jadi plain `:root` CSS var, dipakai consumer via `duration-[var(--duration-slow)]` (bukan `duration-slow`). Tetap 1 sumber kebenaran. - **Wajib:** utility `@media (prefers-reduced-motion: reduce)` yang matiin animasi non-esensial. Ini nggak boleh skip. **SELESAI** — `global.css`, override universal. — TERCAPAI (pondasi). ### 3.2 Pola motion (urut dari dampak tertinggi) 1. **Hover lift** semua row/card interaktif (base). ✅ CLOSED (08 Sep 2026) — diaudit, nol kandidat lain di luar KpiCard (yang udah dari Fase 1/D2). Bukan "belum", tapi memang nggak ada scope lain: nol card/div lain yang genuinely clickable di app. 2. **Fade-in-on-mount** panel + **stagger 40ms** grid KPI. — "mengalir". 🟡 SEBAGIAN — `KpiCard` udah (`animate-in fade-in slide-in-from-bottom-2`, `duration-slow`+`ease-decelerate`), propagasi otomatis ke semua ~14 halaman yang pakai KpiCard. Stagger 40ms BELUM (KpiCard dipanggil manual per-halaman, bukan `.map()` — butuh cara ngasih index tanpa ubah semua call site, belum diputusin). Panel non-KPI (Card biasa) juga belum. 3. **Skeleton → content crossfade** (jangan loncat). ✅ CLOSED (08 Sep 2026) — `KpiCardSkeleton`/`KpiCard` udah shape identik, dan karena `KpiCard` sekarang punya fade-in-on-mount (poin 2), swap-nya OTOMATIS smooth (efek samping, bukan kerjaan terpisah). `DataTable` row-swap sengaja dibiarin instan (pola umum tabel data, fade per-row berisiko "berkedip" di tabel besar). 4. **Number count-up** KPI (0→nilai, data durasi). — high-impact "premium". ✅ SELESAI (08 Sep 2026) — `hooks/useCountUp.js`. Parse-balik string yang udah diformat KpiCard (disambiguasi via suffix %), animasi sekali di mount (dashboard poll 60 detik, nggak boleh re-trigger tiap refresh), snap ke string asli persis di akhir. 5. **Tab indicator slide** (Monitoring tabs, dll). ✅ SELESAI (08 Sep 2026) — ketemu 2 consumer underline-tab hand-rolled (`MasterDataPage.jsx`, `RecycleBinPage.jsx`) yang tiap tombol nyalain border-bottom sendiri (instan). Dibikin `hooks/useTabIndicator.js` (shared measurement logic via `ResizeObserver`, tetap fleksibel — consumer render tombolnya sendiri termasuk ikon custom kayak Lock/Trash2) + 1 `<span>` indicator yang geser posisinya (`transition-[left,width]`, `duration-base`+`ease-standard`). `ui/tabs.jsx` (Radix, pola pill) ternyata belum ada consumer — di luar scope item ini. 6. **Modal/Drawer** enter/exit (slow/accelerate). ✅ **SELESAI** — `dialog.jsx`/`alert-dialog.jsx` tadinya `duration-200` mentah tanpa easing eksplisit, sekarang `duration-[var(--duration-slow)]` + `ease-decelerate` (masuk)/`ease-accelerate` (keluar), overlay & content sama-sama kena. 7. **Status flash** pas data berubah jadi DANGER (pulse 1×). ✅ SELESAI (08 Sep 2026) — `StatusBadge.jsx`. State-diff PROP `status` di komponen presentational sendiri (bukan ubah data-fetching layer) - tetap sesuai DoD. Flash cuma nyala kalau bukan render pertama & status barunya DANGER. CSS `@keyframes status-flash` + React `key` remount trick, otomatis kena `prefers-reduced-motion`. - **Lib:** default pure CSS/Tailwind. `framer-motion` OPSIONAL cuma buat stagger/exit kompleks — timbang bundle dulu (lu sensitif soal ini, 129KB).
