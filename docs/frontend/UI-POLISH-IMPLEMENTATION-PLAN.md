# UI Polish — Rencana Implementasi Sistematis

> **Turunan dari:** `UI-CONSISTENCY-AUDIT.md` (Fase 0).
> **Filosofi:** Design-system-first. Sentuh PRIMITIVE sekali → propagasi otomatis.
> **Prinsip lu (di-hormati):** scope disiplin, nol ubah logic/data, satu perubahan = satu keputusan sadar (didokumentasi), maintainable > pinter.
> **Aturan emas:** JANGAN rombak fondasi yang udah bagus (token, semantic color, component separation, audit trail). Cuma POLES.

## 0. Ringkasan strategi

**Kenapa urutan ini:** tiap fase berdiri di atas fase sebelumnya. Motion (F3) percuma kalau komponennya (F1) belum konsisten. Poles halaman (F2) percuma kalau primitive-nya (F1) belum final. **Aturan kerja tiap langkah:** 1. 1 PR / 1 batch = 1 concern (jangan campur "radius" + "motion" sekaligus). 2. Sebelum ubah primitive → grep pemakaiannya, catat berapa halaman kena. 3. Tiap keputusan visual → tulis komentar `// polish:` di kode + update audit. 4. Habis tiap fase → screenshot before/after (pakai dummy seed biar keliatan). --- ## FASE 1 — PRIMITIVE (fondasi) > Target: begitu ini beres, mayoritas halaman rapi TANPA disentuh langsung. ### 1.1 `utils/formatDate.js` ⏱️ paling instan (A1) - **Buat:** `formatDate(v)` → `04 Jul 2026`; `formatDateTime(v)` → `04 Jul 2026, 14:30`; `formatRelative(v)` → "3 hari lalu" (opsional). - **Pakai:** `dayjs` + `locale('id')` (udah keinstall). - **Ganti:** semua render tanggal mentah (History PM Part/Line, Audit Log, Inventory History, `last_tgl_ganti`). Durasi TERNYATA nggak bisa lewat jalur sama — Tailwind v4 cuma dukung `--ease-*` sebagai custom theme namespace, `--duration-*` di-drop diam-diam. Fix: durasi jadi plain `:root` CSS var, dipakai consumer via `duration-[var(--duration-slow)]` (bukan `duration-slow`). Tetap 1 sumber kebenaran. - **Wajib:** utility `@media (prefers-reduced-motion: reduce)` yang matiin animasi non-esensial. Ini nggak boleh skip. **SELESAI** — `global.css`, override universal. — TERCAPAI (pondasi). ### 3.2 Pola motion (urut dari dampak tertinggi) 1. **Hover lift** semua row/card interaktif (base). — murah, langsung kerasa. ⬜ BELUM diaudit di luar KpiCard (yang udah dari Fase 1/D2). 2. **Fade-in-on-mount** panel + **stagger 40ms** grid KPI. — "mengalir". 🟡 SEBAGIAN — `KpiCard` udah (`animate-in fade-in slide-in-from-bottom-2`, `duration-slow`+`ease-decelerate`), propagasi otomatis ke semua ~14 halaman yang pakai KpiCard. Stagger 40ms BELUM (KpiCard dipanggil manual per-halaman, bukan `.map()` — butuh cara ngasih index tanpa ubah semua call site, belum diputusin). Panel non-KPI (Card biasa) juga belum. 3. **Skeleton → content crossfade** (jangan loncat). — udah 1/2 jalan. ⬜ BELUM diaudit ulang. 4. **Number count-up** KPI (0→nilai, data durasi). — high-impact "premium". ⬜ BELUM — butuh JS state (nggak bisa CSS murni), effort lebih besar dari sisanya. 5. **Tab indicator slide** (Monitoring tabs, dll). ⬜ BELUM. 6. **Modal/Drawer** enter/exit (slow/accelerate). ✅ **SELESAI** — `dialog.jsx`/`alert-dialog.jsx` tadinya `duration-200` mentah tanpa easing eksplisit, sekarang `duration-[var(--duration-slow)]` + `ease-decelerate` (masuk)/`ease-accelerate` (keluar), overlay & content sama-sama kena. 7. **Status flash** pas data berubah jadi DANGER (pulse 1×). ⬜ BELUM. - **Lib:** default pure CSS/Tailwind. `framer-motion` OPSIONAL cuma buat stagger/exit kompleks — timbang bundle dulu (lu sensitif soal ini, 129KB). **Status bundle pasca 3.1+3.2 parsial:** masih ~130.5KB (naik ~0.2KB dari token+animasi baru, nol library ditambahin). **Sisa Fase 3:** item 1/3/4/5/7 di atas + seluruh 3.3 (data-viz). ### 3.3 Data-viz konsisten (A11) - **Cek lib** yang udah keinstall (recharts? chart.js?). Kalau belum & simpel, SVG murni. - **Bahasa viz = token status** (ok/warn/danger). Sparkline mini di KPI (trend harian), progress ring per-part (udah ada di Monitoring — jadiin standar), trend bar Bekidoritsu (kalau relevan). - **Ini keunggulan vs MUI** — MUI nggak kasih ini gratis. Manfaatin. **Exit Fase 3:** buka app kerasa "hidup" — hover responsif, load mengalir, angka count-up, chart nyawa. Ini titik "anjir ini aplikasi beneran ya". --- ## FASE 4 — GLOBAL POLISH & QA - **Typography scale (A7):** kunci display/heading/body/label/caption di doc + terapin.
